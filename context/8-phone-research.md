Use this when a call-list row is "Needs info" because of a bad number, or when the only number is a switchboard that never gets past the gatekeeper.

Where to look (free sources only)
- The company website: header and footer, contact page, office locations page.
- Local office listings for the city where the decision maker works.
- Apollo, only for numbers that are already revealed. A new reveal costs credits and needs approval.

Rules
- Prefer a local office line near the contact over a toll-free main line.
- Never guess or build a number. Save only what a source shows.
- A personal mobile from anywhere but Apollo is off limits.

Save each number with `add_phone_number`: the company, the number as written, what it is (for example "St. Louis office"), source `claude_research`, and where you found it (for example "company website office locations page"). The app skips numbers it already has.

`get_account` shows every number on file with how many dials it has had and how many came back bad, so you can see which ones to replace.
